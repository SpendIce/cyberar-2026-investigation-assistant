# Demostrar ejecución remota ambigua con PsExec y PowerShell

El escenario principal reconstruirá una ejecución remota mediante PsExec y PowerShell y la contrastará con administración legítima semejante. Se eligió porque una herramienta de doble uso obliga a distinguir evidencia de intención y permite demostrar cronología, hipótesis alternativas y abstención; una muestra cuyo contenido ya confirma malware haría trivial el aporte del asistente.
