# Adoptar primero como estación forense portátil

La adopción comenzará con análisis de EVTX en una estación de investigación y podrá evolucionar hacia servidor interno, integración con Wazuh y validación purple-team. Durante el hackathon se recortará antes que maquillar resultados: se cambiará un fixture incoherente, se reducirá contexto o modelo ante mala inferencia y se eliminará cualquier P1 que amenace el recorrido principal; una limitación observada se declarará en lugar de convertirse en una afirmación no respaldada.
