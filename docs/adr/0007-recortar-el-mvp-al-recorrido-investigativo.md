# Recortar el MVP al recorrido investigativo completo

El P0 cubrirá un solo recorrido reproducible: importar EVTX, producir y normalizar una cronología Hayabusa, seleccionar evidencia, ejecutar inferencia local estructurada, validar el hallazgo, navegar sus referencias y exportarlo. Los dos casos, el ensayo de manipulación y el funcionamiento sin red también son obligatorios; Wazuh, Atomic Red Team, chat, grafos, búsqueda vectorial, múltiples formatos, agentes y controles de acceso quedan fuera del camino crítico.
