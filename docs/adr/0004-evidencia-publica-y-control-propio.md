# Combinar evidencia pública sospechosa con un control propio

La evaluación usará un caso PsExec/PowerShell público como actividad sospechosa y una operación administrativa legítima generada en una VM aislada. La verdad de referencia permanecerá separada de los archivos y del contexto entregado al modelo para evitar que nombres, etiquetas ATT&CK o descripciones del escenario revelen la respuesta esperada.
