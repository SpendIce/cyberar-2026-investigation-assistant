# Hacer del caso de investigación la interfaz principal

La experiencia principal será una cronología con hallazgos y evidencia navegable, no un chat libre ni una cola de alertas. Esta forma permite demostrar procedencia, incertidumbre, revisión humana y funcionamiento degradado; una conversación podrá agregarse después sin convertirse en la fuente de verdad del caso.
